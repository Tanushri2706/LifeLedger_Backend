# Technology Decisions
- **Frontend**: Next.js 15, React 19, TypeScript, Tailwind CSS, HeroUI, Magic UI, Aceternity UI, Framer Motion.
- **Backend**: Node.js, Express.js, TypeScript.
- **Database**: MongoDB Atlas (Mongoose).
- **Storage**: Cloudinary.
- **Authentication**: JWT, Google OAuth.
- **Validation**: React Hook Form, Zod.
- **State Management**: TanStack Query, React Context.
- **Maps**: Google Maps API.
- **AI**: Gemini API.

---

# AI Principles
- AI should assist users.
- AI must never claim to replace doctors.
- Always display a medical disclaimer: *"This AI analysis is for informational purposes only and is not a medical diagnosis."*
- Explain reports using simple language.
- Provide educational insights.
- Avoid absolute medical conclusions.
